## Task
Evaluate CSC on datasets where must-link / cannot-link constraints arise naturally.
Compare against SC, Wang (2014), and Lu (2008). Investigate a hybrid CSC (heat-K) variant.

## Key Findings

### Why CSC (kNN) underperforms Lu on Digits and Newsgroups

- **CSC** solves $L_G v = \lambda L_H v$ using a sparse kNN graph. Constraints act as a *reweighting of the objective* — they cannot inject signal absent from $W_G$.
- **Lu** builds a dense heat-diffusion kernel $K = \exp(-t L_\text{norm})$ using 150 eigenvectors, capturing multi-hop global structure. Cannot-link constraints directly modify $K$:
$$\bar{K} = K(I + MK)^{-1}$$
- On **Newsgroups**, the kNN graph on LSA features is structureless (SC ≈ 0). CSC cannot compensate; Lu's dense kernel rescues global topic signal through diffusion.
- On **Digits**, Lu's 150-eigenvector representation is simply richer than CSC's sparse local graph.

### Why CSC (kNN) beats Lu on Olivetti

- With $K=40$ fine-grained clusters and only $N=400$ points, Lu's heat kernel **over-smooths**: nearby clusters from different identities get blended.
- CSC's sparse kNN graph preserves local neighbourhood structure, which fine-grained clustering requires.

### CSC (heat-K) hybrid

Replace sparse $W_G$ with Lu's heat kernel $K$, then apply CSC's constraint mechanism.

**Result:** Best or tied-best on 3 of 4 datasets, but collapses on Digits (0.516) and Olivetti (0.094).

**Why it fails:** $K$ is a complete dense graph, so $d_G[i] \approx N \cdot e^{-2t}$ is large and nearly uniform. The shared normalisation $D = \varepsilon\, d_G + (1-\varepsilon)\, d_H$ is dominated by $d_G$, washing out the constraint signal from the sparse $W_H$.

### Condition summary

| Condition | CSC (kNN) | Lu | CSC (heat-K) |
|---|---|---|---|
| $W_G$ has clear cluster structure | ✓ competitive | ✓ good | ✗ dense $K$ swamps $W_H$ |
| $W_G$ is poorly connected | ✗ can't fix broken numerator | ✓ diffusion rescues it | ✓ best of all |
| $K$ large relative to $N$ | ✓ preserves local structure | ✗ over-smooths | ✗ over-smooths |
| $N$ large (millions) | ✓ sparse, scalable | ✗ $O(N^2)$ memory | ✗ $O(N^2)$ memory |

---

## Proposed Next Step: Sparsified Heat-K

Sparsify $K$ after computing it — keep only the top-$k$ entries per row:
$$W_G^{\text{sparse-K}}_{ij} = K_{ij} \cdot \mathbf{1}[j \in \text{top-}k_i(K)]$$

This retains global manifold structure (fixing Newsgroups) while keeping $\deg_G$ comparable to $\deg_H$ (protecting Digits and Olivetti). Storage cost drops from $O(N^2)$ to $O(Nk)$.
